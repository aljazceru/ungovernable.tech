#### Atomic Swaps
- [TierNolan's atomic swap](https://bitcointalk.org/index.php?topic=193281.msg2224948) - Original atomic cross-chain swap proposal (2013)
- [Bitcoin Script for HTLCs](https://en.bitcoin.it/wiki/Hash_Time_Locked_Contracts) - Hash Time-Locked Contracts for atomic swaps
- [Komodo BarterDEX](https://github.com/KomodoPlatform/komodo-defi-framework) - Decentralized exchange supporting atomic swaps across 95+ chains
- [Liquality](https://liquality.io/) - Atomic swap wallet for BTC/ETH/ERC-20

#### Adaptor Signatures (Scriptless Swaps)
- [Scriptless Scripts](https://lists.linuxfoundation.org/pipermail/bitcoin-dev/2017-August/014998.html) - Andrew Poelstra's adaptor signature concept for privacy-preserving swaps
- [MuSig2 adaptor signatures](https://eprint.iacr.org/2022/807.pdf) - Two-round adaptor signatures for Schnorr
- [secp256kfun adaptor](https://github.com/LLFourn/secp256kfun/tree/main/adaptor) - Rust library for adaptor signatures

#### Cross-Chain Infrastructure
- [COMIT Network](https://github.com/comit-network) - COMIT — an open protocol for trustless cross-chain trading
- [DCRDEX / Bison Wallet](https://github.com/decred/dcrdex) - Decentralized exchange powered by atomic swaps with no KYC, no fees
- [Thorchain](https://thorchain.org/) - Cross-chain liquidity protocol (AMM-based, not atomic swap)
- [Lightning Labs Loop](https://github.com/lightninglabs/loop) - Submarine swaps between on-chain and Lightning
- [xmr-btc-swap](https://github.com/comit-network/xmr-btc-swap) - Trustless Monero-Bitcoin atomic swap
- [Mintlayer](https://www.mintlayer.org/) - Bitcoin-compatible chain with native atomic swaps on mainnet (January 2026)

#### Privacy Analysis
- [Atomic swap privacy](https://eprint.iacr.org/2020/1462.pdf) - On the privacy of atomic swaps and cross-chain transactions
- [Breaking Atomic Swaps](https://eprint.iacr.org/2019/877.pdf) - Privacy analysis of HTLC-based atomic swap protocols
