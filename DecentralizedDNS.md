#### Nostr & Public-Key DNS
- [nomen](https://github.com/ursuscamp/nomen) - Nostr and Bitcoin based naming system
- [pkdns](https://github.com/pubky/pkdns) - pkarr based DNS setup compatible with existing DNS
- [pkarr](https://github.com/pubky/pkarr) - Public Key Addressable Resource Records
- [Nuhvi/pkarr](https://github.com/Nuhvi/pkarr) - Public-Key Addressable Resource Records using Mainline DHT and BEP44 for sovereign TLDs

#### ENS
- [Ethereum Name Service](https://ens.domains/) - Ethereum-based decentralized naming system

#### Cardano DNS
- [blinklabs-io/dns-contracts](https://github.com/blinklabs-io/dns-contracts) - Decentralized DNS service and marketplace contracts on Cardano

#### Handshake
- [Handshake](https://handshake.org/) - Decentralized, permissionless naming protocol replacing Certificate Authorities
- [Handshake GitHub](https://github.com/handshake-org/hsd) - Node implementation and protocol specs
- [Bob Wallet](https://bobwallet.io/) - GUI wallet for Handshake name management
- [Handshake DNS Replacement Guide](https://decentralizers.com/2025/12/02/handshake-dns-replacement-guide/) - 10-step guide to replacing DNS with Handshake (December 2025)
- [Alternative DNS Systems - ENS, Handshake](https://rx-name.net/blog/alternative-dns-systems-ens-handshake-and-other-non-icann-solutions) - Comparison of decentralized DNS alternatives
- [A Practical Guide to Decentralized Websites](https://ens.domains/blog/post/decentralized-websites) - Deploying decentralized websites using ENS, IPFS, Filecoin, and Safe
- [Tokenized DNS Domains with Doma and ENS](https://ens.domains/blog/post/d3-doma) - Doma Protocol enabling DNS domains to function as ENS names

#### Namecoin

- [Namecoin Post-Quantum TLS](https://www.namecoin.org/) - Research on PQ-resistant Namecoin TLS implementation (2025-2026)
- [Namecoin FOSDEM 2026](https://www.namecoin.org/) - Upcoming FOSDEM 2026 presentation
