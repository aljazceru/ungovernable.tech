#### Zero-Knowledge Proof Systems
- [zk-SNARKs](https://eprint.iacr.org/2019/099.pdf) - Succinct Non-Interactive Arguments of Knowledge — compact proofs verifiable in milliseconds
- [Bulletproofs](https://eprint.iacr.org/2017/1066.pdf) - Short proofs for confidential values without trusted setup (Bünz et al., 2018)
- [Halo 2](https://electriccoin.co/blog/halo-2-cryptographic-proof-system/) - Recursive proof composition without trusted setup, used in Zcash Orchard
- [Circom & SnarkJS](https://github.com/iden3/circom) - Domain-specific language and toolchain for writing and verifying zk-SNARK circuits
- [Arkworks](https://github.com/arkworks-rs) - Rust ecosystem for programming and composing zk-SNARK protocols

#### ZK Rollups & Scaling
- [zkSync Era](https://github.com/matter-labs/zksync-era) - ZK rollup on Ethereum supporting smart contracts with native account abstraction
- [Scroll](https://scroll.io/) - Bytecode-level compatible ZK rollup for Ethereum using proof of correctness
- [Polygon zkEVM](https://github.com/0xPolygonHermez/zkevm-rom) - Open-source ZK rollup offering EVM equivalence
- [Starknet](https://starknet.io/) - Layer-2 network using STARK proofs for scalable dApp computation
- [Mina Protocol](https://minaprotocol.com/) - Minimal-blockchain using recursive SNARKs to maintain a constant 22KB chain

#### Privacy-Focused ZK
- [Aztec Network](https://aztec.network/) - Privacy-first ZK rollup enabling private smart contracts on Ethereum
- [Tornado Cash](https://github.com/tornadocash) - Non-custodial Ethereum privacy solution using ZK proofs (note: sanctioned by OFAC)
- [Nocturne](https://nocturne.xyz/) - Privacy protocol using ZK proofs for shielded Ethereum transactions
- [Zcash](https://z.cash/) - Privacy-preserving cryptocurrency using zk-SNARKs (Halo 2)

#### ZK Identity & Credentials
- [Polygon ID](https://github.com/0xPolygonID) - ZK identity protocol for privacy-preserving verification on blockchain
- [zkPass](https://zkpass.io/) - Privacy-preserving identity verification using ZK proofs and TLS
- [anon-aadhaar](https://github.com/anon-aadhaar/anon-aadhaar) - ZK protocol to prove possession of Aadhaar (Indian ID) without revealing identity
