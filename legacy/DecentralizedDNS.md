#### Nostr & Public-Key DNS
- [nomen](https://github.com/ursuscamp/nomen) - Nostr and Bitcoin based naming system
- [pkdns](https://github.com/pubky/pkdns) - pkarr based DNS setup compatible with existing DNS
- [pkarr](https://github.com/pubky/pkarr) - Public Key Addressable Resource Records
- [Nuhvi/pkarr](https://github.com/Nuhvi/pkarr) - Public-Key Addressable Resource Records using Mainline DHT and BEP44 for sovereign TLDs
- [pkdns-publisher](https://github.com/pubky/pkdns-publisher) - Rust service that republishes PKARR DNS records to keep them alive on Mainline DHT
- [Pkarr Introduction](https://github.com/pubky/pkarr/blob/main/docs/introduction.md) - Technical overview of public-key addressable DNS records over Mainline DHT
- [Pubky Core](https://github.com/pubky/pubky-core) - Homeserver and SDK stack for public-key-based censorship-resistant web applications
- [Pubky Nexus](https://github.com/pubky/pubky-nexus) - Backend indexing layer connecting Pubky homeservers to social-app APIs
- [Pubky App](https://github.com/pubky/pubky-app) - Web client for the Pubky social application ecosystem

#### ENS
- [Ethereum Name Service](https://ens.domains/) - Ethereum-based decentralized naming system
- [ENS Documentation](https://docs.ens.domains/) - Official protocol, resolution, registrar, resolver, and developer docs
- [ENSIP-1](https://docs.ens.domains/ensip/1) - Core ENS protocol specification for registry, resolvers, namehash, and registrars
- [ENS Contracts](https://github.com/ensdomains/ens-contracts) - Core smart contracts for ENS registry, registrars, and public resolvers

#### Cardano DNS
- [blinklabs-io/dns-contracts](https://github.com/blinklabs-io/dns-contracts) - Decentralized DNS service and marketplace contracts on Cardano

#### Handshake
- [Handshake](https://handshake.org/) - Decentralized, permissionless naming protocol replacing Certificate Authorities
- [Handshake GitHub](https://github.com/handshake-org/hsd) - Node implementation and protocol specs
- [hnsd](https://github.com/handshake-org/hnsd) - Lightweight SPV resolver daemon for resolving Handshake names locally
- [Awesome Handshake](https://github.com/namebasehq/awesome-handshake) - Curated directory of Handshake sites, resolvers, nameservers, and tutorials
- [Namebase Learning Center](https://learn.namebase.io/about-handshake/about-handshake) - Introductory Handshake docs covering decentralized root-zone ownership
- [Handshake Decentralized SLDs](https://github.com/namebasehq/decentralized-slds) - Proposal for ERC-721 second-level domains anchored to Handshake TLDs
- [Handshake Tools](https://github.com/htools-org) - DANE, site-check, login, and protocol tooling for the Handshake ecosystem
- [Resolving Handshake Domains](https://handypedia.org/resolve) - Handypedia guide comparing hsd, hnsd, Fingertip, Beacon, and remote resolvers
- [Bob Wallet](https://bobwallet.io/) - GUI wallet for Handshake name management
- [Handshake DNS Replacement Guide](https://decentralizers.com/2025/12/02/handshake-dns-replacement-guide/) - 10-step guide to replacing DNS with Handshake (December 2025)
- [Alternative DNS Systems - ENS, Handshake](https://rx-name.net/blog/alternative-dns-systems-ens-handshake-and-other-non-icann-solutions) - Comparison of decentralized DNS alternatives
- [A Practical Guide to Decentralized Websites](https://ens.domains/blog/post/decentralized-websites) - Deploying decentralized websites using ENS, IPFS, Filecoin, and Safe
- [Tokenized DNS Domains with Doma and ENS](https://ens.domains/blog/post/d3-doma) - Doma Protocol enabling DNS domains to function as ENS names
