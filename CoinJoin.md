#### CoinJoin Implementations
- [Wasabi Wallet](https://wasabiwallet.io/) - Privacy-focused Bitcoin wallet with Chaumian CoinJoin
- [Wasabi Wallet GitHub](https://github.com/zkSNACKs/WalletWasabi) - Open source .NET implementation
- [WabiSabi protocol](https://eprint.iacr.org/2021/387) - Flexible CoinJoin with blind signatures, not just equal-output
- [JoinMarket](https://github.com/JoinMarket-Org/joinmarket-clientserver) - Decentralized CoinJoin marketplace — market makers earn fees
- [Jam](https://github.com/joinmarket-webui/jam) - Web UI for JoinMarket

#### Payjoin (P2EP)
- [BIP 78: Payjoin](https://github.com/bitcoin/bips/blob/master/bip-0078.mediawiki) - Pay-to-endpoint: receiver contributes inputs to a payment transaction
- [Payjoin Dev Kit](https://payjoindevkit.org/) - Tools for integrating Payjoin into wallets
- [payjoin](https://github.com/payjoin/rust-payjoin) - Rust library for BIP 78 Payjoin

#### Bitcoin Privacy Tools
- [Samourai Wallet](https://samouraiwallet.com/) - Privacy toolkit with Stonewall, Ricochet (note: developers arrested 2024)
- [Silent Payments (BIP 352)](https://github.com/bitcoin/bips/blob/master/bip-0352.mediawiki) - Reusable payment codes without address reuse
- [BIP 47: Reusable Payment Codes](https://github.com/bitcoin/bips/blob/master/bip-0047.mediawiki) - Payment codes for static payment addresses

- [Sparrow Wallet](https://github.com/sparrowwallet/sparrow) - Desktop Bitcoin wallet focused on security, privacy, and coin control
- [Ashigaru](https://ashigaru.rs/) - Open-source privacy-first Bitcoin wallet forked from Samourai Wallet (Tor-only)

#### Privacy Research
- [Bitcoin Privacy wiki](https://en.bitcoin.it/wiki/Privacy) - Comprehensive Bitcoin privacy guide
- [An Analysis of Non-Deterministic Wallets](https://bitcointalk.org/index.php?topic=3229539.0) - Address clustering and privacy leakage
- [CoinJoin research](https://www.researchgate.net/publication/337904845_An_Analysis_of_Bitcoin%27s_CoinJoin_Transactions) - Academic analysis of CoinJoin transaction patterns
