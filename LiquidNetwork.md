#### Confidential Transactions
- [Confidential Transactions](https://elementsproject.org/features/confidential-transactions) - How Liquid hides transaction amounts using Bulletproofs
- [Bulletproofs paper](https://eprint.iacr.org/2017/1066.pdf) - Bünz et al. (2018) — short proofs for confidential values
- [Greg Maxwell's CT proposal](https://bitcointalk.org/index.php?topic=1078201.0) - Original Confidential Transactions concept (2015)
- [Everyday Guide to Confidential Transactions](https://blog.liquid.net/guide-to-confidential-transactions/) - Technical deep-dive on how CT works on Liquid
- [Elements CT Tutorial](https://elementsproject.org/elements-code-tutorial/confidential-transactions) - Hands-on Elements walkthrough for blinded addresses and confidential transfers

- [go-elements](https://github.com/vulpemventures/go-elements) - Go library for Liquid/Elements transactions and confidential transaction primitives
- [rust-elements](https://github.com/ElementsProject/rust-elements) - Rust library for Elements transaction and block serialization
- [libwally-core](https://github.com/ElementsProject/libwally-core) - Cross-platform wallet primitives with Elements support
- [Liquid Wallet Kit](https://github.com/Blockstream/lwk) - Blockstream Rust toolkit for building Liquid wallets and applications
