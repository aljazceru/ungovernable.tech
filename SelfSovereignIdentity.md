#### W3C Decentralized Identifiers (DIDs)
- [W3C DID Core v1.0](https://www.w3.org/TR/did-core/) - Decentralized Identifiers specification — globally unique, self-owned identifiers
- [W3C DID v1.1](https://www.w3.org/TR/did-1.1/) - Updated DID specification with improved verification methods
- [did:key Method](https://w3c-ccg.github.io/did-key-spec/) - Simple DID method based on expanding a cryptographic public key into a DID Document
- [Microsoft ION](https://github.com/decentralized-identity/ion) - Decentralized DID network built on Bitcoin (Sidetree protocol)
- [did:web Method](https://w3c-ccg.github.io/did-method-web/) - DID method using web domains for DID Document resolution
- [did:ethr Method](https://github.com/uport-project/ethr-did-resolver) - Ethereum-based DID method for blockchain identity

#### Verifiable Credentials
- [W3C Verifiable Credentials](https://www.w3.org/TR/vc-data-model/) - Standard for cryptographically verifiable digital credentials
- [W3C VC Data Model v2.1](https://www.w3.org/news/2026/first-public-working-draft-verifiable-credentials-data-model-v2-1/) - Latest working draft extending the VC standard (2026)
- [W3C VC Implementations](https://github.com/w3c/verifiable-credentials/blob/main/implementations.md) - Comprehensive list of VC implementations across languages
- [OpenID4VP / OpenID4VCI](https://openid.net/openid-for-verifiable-credential-self-certification-to-launch-feb-2026/) - OpenID standards for verifiable presentations and credential issuance
- [Microsoft Decentralized Identity](https://github.com/microsoft/Decentralized-Identity-and-Verifiable-Credentials) - Reference implementations and documentation for DID/VC
- [Dock](https://www.dock.io/) - Self-sovereign identity platform for creating DIDs and Verifiable Credentials
- [Decentralized Identity Foundation](https://identity.foundation/) - Open ecosystem for decentralized identity standards and interoperability
- [did-jwt-vc](https://github.com/decentralized-identity/did-jwt-vc) - Create and verify W3C Verifiable Credentials JWTs
- [Credo](https://github.com/openwalletfoundation/credo) - TypeScript framework for building decentralized identity and VC solutions (OpenWallet Foundation)
- [Veridian Wallet](https://cardanofoundation.org/blog/veridian-digital-identity-platform) - Open-source identity wallet using KERI and ACDC protocols

#### Decentralized PKI
- [DPKI Overview](https://hackernoon.com/decentralized-public-key-infrastructure-dpki-what-is-it-and-why-does-it-matter-babee9d88579) - Decentralized PKI: replacing Certificate Authorities with blockchain-based trust
- [Namecoin](https://namecoin.org/) - Blockchain-based naming system that can serve as decentralized PKI and TLS certificate anchoring
- [PKARR](https://github.com/Nuhvi/pkarr) - Public Key Addressable Resource Records — DNS-like records signed by public keys
- [KERI](https://github.com/decentralized-identity/KERI) - Key Event Receipt Infrastructure for decentralized identifier key management

#### Identity & Privacy
- [ZK Identity](https://github.com/0xPolygonID) - Polygon ID — zero-knowledge identity protocol for privacy-preserving verification
- [anon-aadhaar](https://github.com/anon-aadhaar/anon-aadhaar) - ZK protocol to prove possession of Aadhaar (Indian ID) without revealing identity
- [World ID](https://worldcoin.org/world-id) - Privacy-preserving proof of personhood via iris biometrics with ZK proofs
- [EUDI Wallet](https://european-digital-identity.eu/) - European Digital Identity Wallet under eIDAS 2.0 regulation (2026)

#### Nostr-Based Identity
- [NIP-05](https://github.com/nostr-protocol/nips/blob/master/05.md) - DNS-based identifier mapping for Nostr keys
- [NIP-46: Nostr Connect](https://github.com/nostr-protocol/nips/blob/master/46.md) - Remote key signing protocol for multi-device Nostr identity
- [nsecBunker](https://github.com/kind-0-nostr/nsecbunker) - Self-hosted Nostr key management bunker for secure remote signing
