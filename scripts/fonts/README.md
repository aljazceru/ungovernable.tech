Fonts used to render the share images (assets/og/*.png), vendored so every machine renders them the same.
Archivo (instanced at wght 760, wdth 100) and IBM Plex Mono Medium, both SIL Open Font License 1.1.
The web fonts in assets/fonts/ are the same families (plus Source Serif 4), latin + latin-ext subsets, OFL 1.1.
Web fonts are subset to the glyphs in each unicode-range with unused axis ranges removed. Archivo is shipped as three static widths (66%, 80%, 100%; weight axis 400–800 kept), matching the three font-stretch values the CSS uses.
