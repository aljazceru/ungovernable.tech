Identity and Pseudonymity Sunday — June 28 2026 Weekly Update

published 2026-06-28 4 min read Identity, Social and Trust

DATED BRIEFING // 2026-06-28 // may be outdated

This page reflects what was known on 2026-06-28. It is kept as a record, not maintained as a reference; current knowledge lives in the pillar entries.

TL;DR — This Week

  • Nostr Compass #28 (Jun 24): Sprout rebrands to Buzz; publishes personas, teams, and managed-agent records as relay events. Cross-device read state and per-message read markers replace badge-frontier model.
  • Signer ecosystem: Amber F-Droid availability confirmed; ongoing NIP-46 remote signing refinements (metadata announcements). Clave iOS push-woken background signing in App Store review pipeline. Signet v1.11.x post-bypass hardening.
  • NIP developments: NIP-50 (Search Capability) framework published. NIP-69 (Peer-to-peer Order events) advancing for liquidity pools across P2P platforms. NIP-52 calendar and NIP-22 comment specs active.
  • P2P Trade & Reputation: Mostro/Chama continue Protocol v2 adoption with NIP-44 gift-wraps. NIP-85 Web of Trust scoring (PageRank-based, kind 30382–30385) live at wot.klabo.world.
  • Proof of Personhood: Worldcoin/World ID 2.x SDK adoption and regulatory tracking. IACR papers and social-graph methods (BrightID, Idena) parallel track.
  • Farcaster/Neynar: Post-acquisition integration stable; on-chain FIDs remain decentralized while stewardship centralizes.
  • AI Agent Identity: Buzz (ex-Sprout) and TENEX-style supervision emerging as Nostr-native agent coordination layer.

Freedom-tech takeaway: Nostr's key-based pseudonymity is evolving from social graph to full-stack identity primitive — remote/hardware signers (NIP-46/55), wallet primitives (NIP-60/61), Web of Trust assertions (NIP-85), and now agent/persona events. This stack enables censorship-resistant reputation, P2P commerce, and autonomous AI agents without institutional gatekeepers. The rebrand and event standardization signal maturing discoverability and multi-device sovereignty.

The Week in Detail

Nostr Compass #28 & Protocol Maturation

Nostr Compass #28 (June 24, 2026) highlights the Sprout → Buzz rebrand. Buzz now publishes personas, teams, and managed-agent records directly as Nostr relay events. This extends the identity model beyond single keys to composable agent and team identities — critical for AI-augmented pseudonymity.

  • Cross-device read state synchronization and per-message read markers replace older badge models.
  • Builds on NIP-89 (Recommended Application Handlers) and emerging agent coordination patterns.
  • Source: Nostr Compass #28

Additional NIP activity: - NIP-50 Search Capability: General extensible framework for queries beyond structured tags/IDs. Published ~June 21–26 window. - NIP-69 P2P Order events: Standard for peer-to-peer orders enabling cross-platform liquidity pools (mainnet/testnet/signet, onchain/Lightning/Liquid layers). - Continued refinement of NIP-46 (Remote Signing) with remote-signer metadata announcements.

Signer Hardening & Remote Signing (NIP-46 / NIP-55)

  • Amber (Android NIP-46/55 signer): Confirmed F-Droid distribution; reliable for key segregation and migration workflows. Continues to dominate Android signer recommendations.
  • Clave (iOS): Push-woken background signing (build 102 submitted) enables signing with app closed using BIP-340 Schnorr + replay guards.
  • Signet: Post v1.11.0 admin-command verification fixes (seal/rumor separation) remain the reference implementation for secure remote signer command handling.
  • Trend: Signers are becoming load-bearing — keys never leave dedicated hardware/software boundaries.

Related: NIP-46 updates emphasize differentiating remote-signer-pubkey vs user-pubkey and mandatory get_public_key after connect.

Web of Trust & Reputation Systems (NIP-85)

  • wot-scoring (joelklabo): PageRank-based trust scoring crawler publishing NIP-85 events (kinds 30382–30385). Live at wot.klabo.world.
  • Nostr WoT browser extension and foundation work: Portable WoT layer with trust badges, follow-graph analysis, and Lightning integration.
  • Nostr WoT Foundation: Netherlands-based org advancing open-source WoT protocols on Nostr.
  • Maturity: Moving from experimental to deployable scoring with on-relay persistence. Enables Sybil-resistant filtering without central authorities.

See also Proof of Personhood and Sybil Resistance for complementary biometric and social-graph approaches.

Proof of Personhood & Broader Identity Landscape

  • World ID 2.x: Ongoing hardware Orb updates, SDK adoption, and regulatory navigation. Remains the leading biometric PoP deployment.
  • Parallel tracks: Idena (synchronous validation), BrightID (social graph), Polkadot ZK-PoP roadmap, and academic IACR eprint frameworks.
  • Use case growth: DAO voting, airdrops, content moderation without doxxing.

Real-World Deployments & Trade-offs

  • Pseudonymous Trade: Mostro/Chama P2P stacks using NIP-44 gift-wrapped direct messages for reputation accumulation tied to keys, not accounts.
  • AI Agents: Buzz personas + NIP-46 signers enable persistent agent identities with verifiable actions.
  • Migration & Recovery: Emphasis on key custody hygiene; no recovery mechanisms by design (self-sovereign trade-off).
  • NIP-05: Continued domain-based verification for human-readable handles; trust via DNS control + WoT overlays.
