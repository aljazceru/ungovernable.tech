Mix Networks Friday — July 03 2026 Weekly Update

published 2026-07-03 3 min read Anonymity Networks

DATED BRIEFING // 2026-07-03 // may be outdated

This page reflects what was known on 2026-07-03. It is kept as a record, not maintained as a reference; current knowledge lives in the pillar entries.

TL;DR — This Week

  • Tor / Tor Browser: Tor Browser 15.0.17 released June 28, 2026 (security updates to Tor 0.4.9.11). Tor Browser 16.0a8 alpha released July 2, 2026. Legacy 0.4.8 sunsetting remains on track.
  • Arti: Arti 2.5.0 (June 30, 2026) — Counter Galois Onion (CGO) promoted to stable; Congestion Control enabled by default for improved performance. Major milestone for the Rust Tor implementation.
  • Tails: Tails 7.9.1 (July 1, 2026) — Updates to Tor Browser 15.0.17, Tor 0.4.9.11, and Linux kernel 6.12.94 fixing privilege-escalation CVEs (DirtyClone CVE-2026-43503 and PACKET_EDIT_MEME CVE-2026-46331).
  • Nym / NymVPN: Continued momentum from v2026.10 (June). High-profile integrations: Edge wallet now supports NYM token + native Nym Mixnet routing (recent July 2026 rollout). Focus on wallet ecosystem and post-quantum features.
  • I2P: No new release; 2.12.0 (April 2026) current. SSU2-PQ work ongoing toward 2.13.0.
  • Research & Ecosystem: CGO stability and congestion control mark tangible progress on Tor performance without sacrificing anonymity. Nym's wallet integrations demonstrate real-world composability with crypto tools. No major new academic papers surfaced this week.
  • Freedom-tech takeaway: Arti is production-ready for more use cases; pair Tor/Arti with Nym for layered metadata protection. Tails remains the go-to live environment. Monitor CGO deployment for next-gen onion services.

The Week in Detail

Tor Project: Browser releases + Arti CGO stable

Tor Browser 15.0.17 (June 28) delivers security backports and Tor 0.4.9.11 updates. The v15 series continues as the stable channel.

Tor Browser 16.0a8 (July 2) advances the alpha track based on Firefox Rapid Release, signaling faster iteration for testing new features.

Arti 2.5.0 (June 30) is a landmark release: - Counter Galois Onion (CGO) — the next-generation onion encryption scheme — is now stable and included in full feature builds. - Congestion Control enabled by default, improving throughput and latency characteristics. - This accelerates the migration path away from legacy C tor toward a fully Rust-based, maintainable implementation.

Tails 7.9.1 (July 1) integrates the above Tor updates plus critical kernel hardening against two privilege-escalation vulnerabilities. Automatic upgrades available for existing Tails 7.x installs.

GitHub / Primary Sources: - Tor Blog: https://blog.torproject.org/ - Arti 2.5.0 announcement: https://blog.torproject.org/arti_2_5_0_released/ - Tails 7.9.1: https://blog.torproject.org/new-release-tails-7_9_1/ - Tor Browser releases on forum and distribution directory.

Nym: Ecosystem integrations accelerating

NymVPN continues post-v2026.10 iteration with focus on usability and decentralization. Key development this week: - Edge wallet integration (live July 2026): Multi-asset wallet adds NYM token support + native Nym Mixnet routing. Enables on-chain privacy + network-level metadata protection in a single self-custodial app. First major wallet to embed mixnet routing. - Ongoing emphasis on post-quantum keys, split-tunneling, ad-blocking, and custom DNS from prior roadmap. - Roadmap 2026 goals (decentralization, performance, token utility) remain on track; wallet integrations are a concrete step toward composability with privacy-preserving crypto tools.

GitHub / Primary Sources: - Nym blog & roadmap: https://nym.com/blog/ - Edge wallet announcement: https://edge.app/blog/company-news/... - nym-vpn-client repo: https://github.com/nymtech/nym-vpn-client (active commits through July 2)

I2P and Other Mixnets

  • I2P remains at 2.12.0 (April 2026). Development continues on SSU2-PQ transport for 2.13.0 (target August timeframe from prior reports).
  • No significant public updates on Loopix/Katzenpost/HORNET or HOPR this week. Nym and Tor dominate real-world visibility and development velocity.
  • Broader ecosystem: Continued academic and implementation focus on hybrid PQ schemes and cover traffic optimizations.
