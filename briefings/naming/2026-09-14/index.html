2. Root KSK rollover — T-27 days, Reveal Day date still pending

T-27 days to Oct 11, 2026 KSK-2024 cutover; old-key retirement Jan 2027. ICANN's Aug 11 guidance document "What to Expect During the Root KSK Rollover" is the primary reference; ICANN blog Jul 27 "Preparing for the Root Zone KSK Rollover: What You Need to Know" is the executive summary. Risk to DNSSEC-validating resolvers that haven't loaded KSK-2024: total DNS resolution failure.

Recent comms: - Aug 26 EMEA Webinar Series — ICANN engagement-calendar entry + ISOC Live recording (password BmEKv5ue?\). - Sep 4–6 ICANN Board LA workshop — agenda included New gTLD 2026 Round; Reveal Day date still expected in mid-Sep window per ICANN's Aug 13 announcement. - Sep 9 ICANN blog "Chair's Blog: September Board Workshop Preview" — the pre-meeting chair's preview. No Reveal Day date confirmed publicly yet as of Sep 14.

Critical post-rollover fact for the decentralized-DNS stack: DNSSEC-validating resolvers are the universal choke point. Any naming system that uses DNSSEC anchoring (ENS DNSSEC import, Namecoin via ncp11, Handshake via resolver trust) inherits the dependency. Decentralized alternatives that don't use DNSSEC at all (GNS, PKARR/PKDNS, Tor .onion, Yggdrasil IPv6, Namecoin's P2P mode, Slashtags) are unaffected. This is the only scheduled global DNS event in 2026.

3. ENSv2 remains on Ethereum L1

ENS’s Surge proposal is dated 17 November 2025. Its later announcement, on 6 February 2026, says ENSv2 will deploy exclusively on Ethereum L1 and Namechain development will cease. The older proposal does not establish a September revival. See ENS.

The Sep 7 weekly cited v0.3.1 as current; this is now out of date — v0.4.1 is the live release line. The repo is community-led under the handshake-rs GitHub organization, separate from handshake-org.

hsd (handshake-org/hsd) — dormant: - Last commit: 2025-08-22 (698e252 Merge PR #944 from 'nodech/fix-partial-open') — over one year stale. - Last tagged release: v2.4.0 from 2021-04-02 — no v3.x. - PR #952 (the long-open hard-fork proposal that the Aug 24 weekly noted as frozen since May 11) is still not landed.

This means Handshake core protocol development is effectively paused; only the Rust ecosystem under handshake-rs is shipping, and the focus is on the swap/auction layer (Shakescape V1) rather than consensus. 6. ENS DAO Sep 8 burst — research + SDK + service-provider reports

The Sep 7 weekly captured the Sep 1 burst. The Sep 8 forum additions are fewer but higher-signal:

  • [Research] ENS-GR-01: A Ten-Proposal Governance Record for Delegation Incentives](https://discuss.ens.domains/) — DAO-Governance, 0 replies, Sep 8. The "GR-01" suggests a structured research series (Governance Research #01) on delegation-incentive mechanisms. Likely author: a delegate researcher. Not yet commented.
  • ensforge: A unified TypeScript SDK for ENSv1 and ENSv2 — ENS Development, 1 reply, Sep 8. The first single-API TypeScript SDK spanning both ENSv1 and ENSv2 contracts. This is a meaningful dev-experience improvement — the current state is two parallel SDK paths (viem / ethers v5 against ENSv1; new viem-style against ENSv2 Sepolia). A unified SDK reduces the migration cliff.
  • Blockful - service provider reports and updates — 11 replies, Sep 8. Blockful is one of the active ENS service providers; their regular reports include Subname Registrar and Governor Nexus work. The Sep 7 weekly captured the Blockful completes Governor Nexus implementation milestone from Newsletter #119.
  • ENS Newsletter #120 expected ~Sep 15 — Newsletter #119 was Sep 1; the cadence is every ~2 weeks (Aug 18 #118, Sep 1 #119, Sep 15 #120 projected).

Still open from Sep 1 burst (carried from Sep 7 weekly, no resolution): - ENSIP-28: ENS Name Owned Accounts — Standards, 11 replies, Sep 2. Self-asserted claims attaching Safes, token-bound accounts, agent wallets via ENSIP-24 records. - [RFC] Privacy-Preserving Names: ENSIP for Stealth Address Resolution](https://discuss.ens.domains/t/rfc-privacy-preserving-names-ensip-for-stealth-address-resolution/22354) — 8+ replies as of Sep 1, build on Fluidkey + Cloaked flows. Fluidkey has run this in production for 2+ years supporting $1B+ transfer volumes across 28k users. - ENSIP: Text Record Attestations — class + schema records for organizational metadata, draft in progress. - Stealth-address ENSIP discussion adds implementation details — integrity checks for wildcard names, reference implementation review offered. - DNSSEC oracle replacement proposal live — security-critical; under-specified for DNSSEC trust anchoring.
