#### Nostr Protocol
- [Nostr](https://nostr.com/) - Notes and Other Stuff Transmitted by Relays — minimalist decentralized social protocol
- [NIP-01](https://github.com/nostr-protocol/nips/blob/master/01.md) - Core protocol specification: events, kinds, relays
- [nostr-protocol/nips](https://github.com/nostr-protocol/nips) - Nostr Implementation Possibilities — protocol extension proposals
- [nostr-tools](https://github.com/nbd-wtf/nostr-tools) - JavaScript library for building Nostr clients
- [nostr-rs](https://github.com/rust-nostr/nostr) - Rust Nostr library with FFI bindings
- [nostr-sdk](https://github.com/rust-nostr/nostr-sdk) - High-level SDK for building Nostr applications in Rust/Python/JS
- [nostr.how](https://nostr.how/zh/the-protocol) - Comprehensive Chinese documentation on Nostr protocol

#### Nostr Clients
- [Damus](https://damus.io/) - iOS Nostr client (Swift)
- [Amethyst](https://github.com/vitorpamplona/amethyst) - Android Nostr client - v1.06.0 released early 2026 with NIP-100 support
- [Primal](https://primal.net/) - Cross-platform Nostr client with social feed - v3.0 released early 2026
- [Snort](https://github.com/v0l/snort) - Web-based Nostr client (React)
- [Gossip](https://github.com/mikedilger/gossip) - Native desktop Nostr client in Rust
- [Coracle](https://github.com/nickvdyck/coracle) - Web Nostr client with relay management
- [Notedeck](https://nostr.co.uk/news/) - Nostr client v0.8 released early 2026

#### Nostr Relays
- [nostr-rs-relay](https://github.com/scsibug/nostr-rs-relay) - Rust-based Nostr relay with SQLite storage
- [strfry](https://github.com/hoytech/strfry) - High-performance C++ Nostr relay
- [nostr-ts-relay](https://github.com/Cameri/nostr-ts-relay) - TypeScript relay implementation
- [nostrcheck-server](https://github.com/quentintaranpino/nostrcheck-server) - Self-hostable Nostr service server with relay, NIP-96/Blossom file hosting, NIP-05, NWC, and WoT
- [NostrGator](https://github.com/Grumpified-OGGVCT/NostrGator) - Docker stack for sovereign Nostr relays, file hosting, Lightning wallet integration, and monitoring

- [awesome-nostr](https://github.com/aljazceru/awesome-nostr) - Curated list of Nostr projects and resources
- [NostrHub](https://soapbox.pub/blog/announcing-nostrhub) - NIPs, apps, and repos discovery platform

#### Nostr Payments & Compute
- [Cashu NUTs](https://github.com/cashubtc/nuts) - Protocol specifications for Cashu ecash wallets and mints, including Nostr mint backup
- [Routstr Core](https://github.com/routstr/routstr-core) - Nostr discovery plus Cashu micropayments for permissionless API/inference routing
- [NIP-47](https://github.com/nostr-protocol/nips/blob/master/47.md) - Nostr Wallet Connect specification for controlling Lightning wallets over Nostr
- [Nostr Wallet Connect Docs](https://docs.nwc.dev/contribute/specification) - Official NWC protocol documentation and implementation guidance
- [Alby NWC App](https://github.com/getAlby/nwc.getalby.com) - Go application for connecting apps to a Lightning node or wallet over Nostr

#### Nostr & Identity
- [NIP-05](https://github.com/nostr-protocol/nips/blob/master/05.md) - Mapping Nostr keys to DNS-based identifiers
- [NIP-19](https://github.com/nostr-protocol/nips/blob/master/19.md) - bech32-encoded entities (nsec, npub, note, nprofile, nevent)
- [NIP-26](https://github.com/nostr-protocol/nips/blob/master/26.md) - Delegated event signing
- [NIP-46](https://github.com/nostr-protocol/nips/blob/master/46.md) - Nostr Connect — remote signing for multi-device
- [NIP-98](https://nips.nostr.com/98) - HTTP Auth — ephemeral events for authorizing HTTP requests
