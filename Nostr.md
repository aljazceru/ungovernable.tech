#### Nostr Protocol
- [Nostr](https://nostr.com/) - Notes and Other Stuff Transmitted by Relays — minimalist decentralized social protocol
- [NIP-01](https://github.com/nostr-protocol/nips/blob/master/01.md) - Core protocol specification: events, kinds, relays
- [nostr-protocol/nips](https://github.com/nostr-protocol/nips) - Nostr Implementation Possibilities — protocol extension proposals
- [nostr-tools](https://github.com/nbd-wtf/nostr-tools) - JavaScript library for building Nostr clients
- [nostr-rs](https://github.com/rust-nostr/nostr) - Rust Nostr library with FFI bindings
- [nostr-sdk](https://github.com/rust-nostr/nostr-sdk) - High-level SDK for building Nostr applications in Rust/Python/JS

#### Nostr Clients
- [Damus](https://damus.io/) - iOS Nostr client (Swift)
- [Amethyst](https://github.com/vitorpamplona/amethyst) - Android Nostr client - v1.06.0 released early 2026 with NIP-100 support
- [Primal](https://primal.net/) - Cross-platform Nostr client with social feed - v3.0 released early 2026
- [Snort](https://github.com/v0l/snort) - Web-based Nostr client (React)
- [Gossip](https://github.com/mikedilger/gossip) - Native desktop Nostr client in Rust
- [Coracle](https://github.com/nickvdyck/coracle) - Web Nostr client with relay management
- [Notedeck](https://nostr.co.uk/news/) - Nostr client v0.8 released early 2026

#### Nostr Relays
- [nostr-rs-relay](https://github.com/scsibug/nostr-rs-relay) - Rust-based Nostr relay with SQLite storage
- [strfry](https://github.com/hoytech/strfry) - High-performance C++ Nostr relay
- [nostr-ts-relay](https://github.com/Cameri/nostr-ts-relay) - TypeScript relay implementation
