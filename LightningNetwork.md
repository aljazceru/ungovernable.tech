#### Lightning Network
- [Lightning Network](https://lightning.network/) - Bitcoin Layer-2 payment channel network for instant off-chain transactions
- [Lightning Labs](https://lightninglabs.com/) - Company building Lightning infrastructure (LND, Loop, Pool, Taproot Assets)
- [Core Lightning (CLN)](https://github.com/ElementsProject/lightning) - Blockstream's Lightning implementation in C
- [LND](https://github.com/lightningnetwork/lnd) - Lightning Network Daemon by Lightning Labs
- [LDK](https://github.com/lightningdevkit/rust-lightning) - Lightning Development Kit — modular library for building Lightning nodes
- [BOLT Specifications](https://github.com/lightning/bolts) - Basis of Lightning Technology protocol specifications
- [BOLT 12: Offers](https://github.com/lightning/bolts/blob/master/xx-offer-encoding.md) - Recurring payments, refunds, and more flexible invoiceless payment flows
- [Lightning Loop](https://github.com/lightninglabs/loop) - Non-custodial submarine swaps between Lightning and on-chain
- [Lightning Pool](https://github.com/lightninglabs/pool) - Marketplace for Lightning channel leases
- [Mutiny Wallet](https://github.com/MutinyWallet/mutiny-node) - Tiny Lightning node that runs in the browser via WASM
- [phinx](https://github.com/phinxLink/phinx) - Lightning node in a web extension

#### Discreet Log Contracts (DLCs)
- [DLC.spec](https://github.com/discreetlogcontracts/dlcspecs) - Discreet Log Contracts specification
- [DLCs on Lightning](https://adiabat.github.io/dlc.pdf) - Original paper by Tadge Dryja (2018)
- [DLC.Link](https://github.com/dlc-link/dlc-clients) - DLC infrastructure for decentralized Bitcoin derivatives
- [DLC Markets](https://dlcmarkets.com/) - Bitcoin-native derivatives platform using DLCs
- [gaborbudiao/dlc-oracle](https://github.com/gaborbudiao/dlc-oracle) - Oracle implementation for DLC attestations
- [cryptogarageinc/dlc-spec](https://github.com/cryptogarageinc/dlc-spec) - DLC reference implementation and tools

#### Lightning Privacy
- [BOLT 4: Onion Routing](https://github.com/lightning/bolts/blob/master/04-onion-routing.md) - Sphinx-based onion routing for Lightning payments
- [Route Blinding (BOLT 4)](https://github.com/lightning/bolts/pull/765) - Recipient privacy via blinded paths
- [Lightning Privacy Handbook](https://lnprivacy.github.io/) - Comprehensive guide to Lightning privacy practices
