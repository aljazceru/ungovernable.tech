#### Browser Hardening
- [Arkenfox user.js](https://github.com/arkenfox/user.js) - Firefox privacy, security, anti-tracking, and fingerprint-resistance configuration template
- [Tor Browser](https://www.torproject.org/download/) - Hardened Firefox browser routed through Tor for strong anonymity sets
- [LibreWolf](https://librewolf.net/) - Firefox fork with privacy defaults, telemetry removal, and fingerprinting protections
- [Mullvad Browser](https://github.com/mullvad/mullvad-browser) - Tor Project and Mullvad privacy browser designed to reduce fingerprinting without Tor routing
- [uBlock Origin](https://github.com/gorhill/uBlock) - Efficient wide-spectrum blocker for ads, trackers, malware, and coin miners
- [ClearURLs](https://github.com/ClearURLs/Addon) - Browser extension that removes tracking parameters from URLs
- [Privacy Possum](https://github.com/cowlicks/privacypossum) - Browser extension that reduces and falsifies data collected by commercial trackers

#### Mobile & Device Hardening
- [GrapheneOS](https://github.com/GrapheneOS/platform_manifest) - Android privacy and security hardening project for supported Pixel devices
- [Orbot](https://github.com/guardianproject/orbot) - Tor VPN/proxy app for Android by Guardian Project
- [Rethink DNS + Firewall](https://github.com/celzero/rethink-app) - Android encrypted DNS, WireGuard proxifier, app firewall, and connection tracker
- [TrackerControl](https://github.com/TrackerControl/tracker-control-android) - Android app for monitoring and blocking hidden tracker connections across installed apps
- [Exodus Privacy](https://github.com/Exodus-Privacy/exodus) - Platform for auditing trackers and privacy risks in Android applications

#### DNS & Network Blocking
- [HaGeZi DNS Blocklists](https://github.com/hagezi/dns-blocklists) - Maintained DNS blocklists for ads, telemetry, phishing, malware, and tracking domains

#### Private Search
- [Whoogle Search](https://github.com/benbusby/whoogle-search) - Self-hosted, ad-free Google metasearch proxy; final release in 2026 due to Google blocking

#### Fingerprinting Tests
- [CreepJS](https://github.com/abrahamjuliot/creepjs) - Browser fingerprinting test suite for auditing how trackable a browser/device is
