## Akash — Mainnet 18 Activated June 11, BME Burn Rate Accelerating

### Mainnet 18 Upgrade — June 11, 2026

Akash Network's Mainnet 18 upgrade activated at block #27,230,465 on **June 11, 2026 at approximately 14:00 UTC**, introducing two production features:

**AEP-82 — Resource Reclamation (Completed June 11)**
Previously, when a provider terminated a lease, the only option was immediate closure — leaving tenant workloads with no graceful shutdown window. Resource Reclamation adds a structured exit mechanism:
- Providers can signal intent to close a lease within a defined grace period
- Tenants receive advance notice and can migrate workloads before termination
- On-chain escrow protects deposits during the transition
- Eliminates abrupt data loss from provider-side terminations

**Oracle v2 — Wall-Clock Timestamps**
Replaces block-height references for staleness detection, TWAP calculations, and price queries. Block-height-based staleness is fragile when block times vary; wall-clock timestamps provide deterministic oracle behavior independent of chain throughput.

**Market Order Close Fix** — corrects edge cases in closing market orders.

### BME Burn Momentum

The BME mechanism (live March 23, 2026) is the first major test of tokenomics-driven deflation in a DePIN compute network at this scale.

The AKT/ACT (stablecoin output from BME) dual-token model is functioning as designed: providers receive stable ACT, tenants burn AKT, speculation is separated from settlement.

### Confidential Computing Path — AEP-65 Live, DOOR SDK Progress

AEP-65 Confidential Computing with TEE went live May 19, 2026. The community DOOOR SDK project (github.com/akash-network/discussions/872) continues developing the integration layer for TEE attestation into Akash workloads. AEP-29 (Hardware Verification using Trusted Execution) provides provider-side hardware attestation live on-chain.

The combination of AEP-65 (confidential workloads), AEP-29 (provider attestation), and BME (stable pricing) positions Akash as a full-spectrum decentralized cloud — from open containers to TEE-isolated confidential compute.

## Fluence — Instant GPU Access Live, FLT Grid League

### GPU Containers and VMs Now Instant-Access

Fluence announced (via X/@fluence_project, June 2026) that **GPU Containers, Virtual Machines, and Bare Metal deployments** are now available for instant access via the Fluence Console — no waitlist, no gating. This is a significant UX step from the previous gated beta.

The Fluence Console now provides:
- **GPU Containers**: isolated GPU-accelerated workloads in managed containers
- **Virtual Machines**: full VM deployments for more complex workloads
- **Bare Metal**: dedicated hardware for high-performance or latency-sensitive jobs
- USDC stablecoin pricing (no crypto volatility for enterprise bills)
- Arbitrum Orbit L2 fee structure (low gas vs. Ethereum L1)

### FLT Grid League on Gate

Fluence launched a **FLT Grid League** competition on Gate.io, rewarding traders who generate volume in the FLT-USDT pair with a share of **3,000 USDC** in prizes. The competition ties speculative trading activity to FLT liquidity and network awareness — a DePIN-adjacent token incentive pattern.

### DAO Governance Migration

Fluence DAO governance has migrated from Tally to the native **Token App** (flt.fluence.network/governance). All governance functions — voting, proposal creation, DAO updates — are now accessible natively within the Fluence ecosystem. Tally's shutdown for many protocols makes native token governance the canonical path.

### SuperAI Conference Presence

Fluence exhibited at **SuperAI Conference** (Singapore, June 2026), demonstrating GPU availability from the Fluence network alongside io.net. The booth showcased Fluence's global GPU cluster network, available locations, and the new GPU Auction mechanism for price discovery on compute capacity.
