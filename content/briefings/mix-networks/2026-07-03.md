## The Week in Detail

### Tor Project: Browser releases + Arti CGO stable

**Tor Browser 15.0.17** (June 28) delivers security backports and Tor 0.4.9.11 updates. The v15 series continues as the stable channel.

**Tor Browser 16.0a8** (July 2) advances the alpha track based on Firefox Rapid Release, signaling faster iteration for testing new features.

**Arti 2.5.0** (June 30) is a landmark release:
- Counter Galois Onion (CGO) — the next-generation onion encryption scheme — is now stable and included in full feature builds.
- Congestion Control enabled by default, improving throughput and latency characteristics.
- This accelerates the migration path away from legacy C tor toward a fully Rust-based, maintainable implementation.

**Tails 7.9.1** (July 1) integrates the above Tor updates plus critical kernel hardening against two privilege-escalation vulnerabilities. Automatic upgrades available for existing Tails 7.x installs.

### Nym: Ecosystem integrations accelerating

NymVPN continues post-v2026.10 iteration with focus on usability and decentralization. Key development this week:
- **Edge wallet integration** (live July 2026): Multi-asset wallet adds NYM token support + native Nym Mixnet routing. Enables on-chain privacy + network-level metadata protection in a single self-custodial app. First major wallet to embed mixnet routing.
- Ongoing emphasis on post-quantum keys, split-tunneling, ad-blocking, and custom DNS from prior roadmap.
- Roadmap 2026 goals (decentralization, performance, token utility) remain on track; wallet integrations are a concrete step toward composability with privacy-preserving crypto tools.
