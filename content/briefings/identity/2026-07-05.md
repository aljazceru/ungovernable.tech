**Freedom-tech takeaway**: Nostr's key-based pseudonymity is solidifying into a full-stack sovereign identity layer. Reputation (NIP-85) and PoP tools layer on top for Sybil resistance without doxxing. The week signals production hardening for ungovernable, pseudonymous coordination at scale.

## The Week in Detail

### Nostr Compass #29 & Protocol Maturation
Nostr Compass #29 (July 1, 2026) emphasizes infrastructure for private, agentic, and mesh-native identity:

- **FIPS v0.4.0** (jmcorgan/fips): Private self-organizing P2P mesh using Nostr keypairs as node identities. Adds outbound Nym mixnet transport (via nym-socks5-client for cover traffic and correlation resistance), opt-in mDNS/DNS-SD LAN discovery, hitless rekey under loss, data-plane performance overhaul, OpenWrt/Nix packaging. Wire-compatible with v0.3.0. Includes sidecar Nostr relay examples over mixnet. Directly strengthens pseudonymous mesh identity and off-grid use.
  - GitHub: https://github.com/jmcorgan/fips/releases/tag/v0.4.0
  - Ties into [05-Off-Grid-Networks](/pillars/mesh/) and mixnet privacy.

- **Buzz v0.3.38** (block/buzz, ex-Sprout): Hardens attack surface on relay-exposed persona/team/agent events (NIP-OA attestations); generalized model selection (new Databricks v2 backend). Continues publishing composable identities as signed relay events for AI-human collaboration.
  - GitHub: https://github.com/block/buzz
  - Desktop releases and performance work ongoing.

- **CustID v0.1.10-beta**: First public beta of mobile identity vault on Nostr + SISTR. Hardware-backed secure storage for multiple npub/nsec identities; acts as NIP-46 remote signer; NFC/QR challenge-response for physical/online access. Background NIP-65 optimizations for bunker viability. Zero-knowledge flows planned.
  - Directly advances key custody and pseudonymity portability on mobile.
  - Source: zapstore.dev listing.

- Additional: Whitenoise Linux (desktop Marmot/MLS client), myco (P2P nsite sharing over FIPS mesh + BLE), Nostr Codex Phone (remote Codex agent control over encrypted DMs), Amethyst/Notedeck/Applesauce updates with NIP-89, NIP-37, NIP-52, NIP-22 support.

NIPs repo merges: relay roles event, NIP-44 byte limit removal, NIP-34 fork semantics, NIP-46 client metadata, NIP-86 signevent method. Deep dives on NIP-86 (Relay Management API) and NIP-89 (Recommended Application Handlers).

### Signer Hardening & Remote Signing (NIP-46 / NIP-55)
- **Clave (iOS)**: Accepted to App Store; push-woken background signing live.
- **Signet 1.20.0**: Browser extension now handles NIP-46 requests without keeping dashboard tab open; live toolbar badge from SSE stream; improved approval flows.
  - Source: freedom.tech Nostr releases tracker.
- **Amber (Android)**: v6.2.2+ adds native icons, NIP-46 client metadata persistence, kind 30618 support, logs export.
- Trend: Signers are production load-bearing with metadata hygiene and seamless integration. Keys remain segregated.

- NIP-85 (Trusted Assertions) remains draft/optional. Discussion continues around limitations for real-time personalized ranking (some projects like Vertex prefer DVMS approaches instead).
- wot-scoring and Nostr WoT extension/browser tools from prior weeks continue adoption.
- See [Proof of Personhood and Sybil Resistance](/kb/proof-of-personhood/) for complementary approaches.

### Proof of Personhood & Broader Identity Landscape
- **World ID**: Ongoing enterprise integrations (Tinder, Zoom, Docusign, Vercel, Okta) with new account-based architecture (key rotation, recovery, multi-key, sessions, one-time nullifiers). Public beta app for managing proof-of-human. Biometric Orb + SDK focus on private, portable verification.
  - Source: world.org announcements (April 2026 updates still driving momentum).
- Parallel: BrightID, Idena, academic IACR frameworks, Polkadot ZK-PoP.

### Real-World Deployments & Trade-offs
- **Agentic Identity**: Buzz personas/teams + NIP-46 signers enable persistent, verifiable AI agent identities with policy controls and cross-provider model support. Nostr as control plane for local/remote agents (Codex Phone, etc.).
- **Mesh Pseudonymity**: FIPS nodes use Nostr keypairs; myco enables offline app/identity sharing. Extends ungovernable identity to LAN/off-grid.
- **Custody & Recovery**: CustID emphasizes hardware-backed multi-identity vaults + NFC challenges; self-sovereign trade-off (no easy recovery) remains core.
- **P2P Trade/Reputation**: Mostro v0.14.0 updates (NIP-69) continue; NIP-85 overlays for trust scoring.
- **NIP-05 & Handles**: Domain verification persists alongside WoT.
