  • Tahoe-LAFS source — Canonical repository for the encrypted distributed storage system
  • Tahoe-LAFS documentation — Client and server setup, architecture and grid administration

Sync and collaborative data

  • Syncthing — Folder synchronization between approved devices
  • Automerge — Local-first synchronization with concurrent merging and document history
  • Yjs documentation — Shared CRDT types, editor integrations and network providers
  • CryptPad — Collaborative documents with client-side encryption
  • Local-first software — Ink & Switch essay on local copies, offline work, collaboration and user control

Offline libraries

  • Kiwix Reader — Read Wikipedia and other ZIM archives without an internet connection

Replication libraries and blob servers

  • Hypercore — Signed Merkle-tree logs with sparse replication and a truncation API
  • Hyperdrive — Distributed filesystem APIs with version checkouts and explicit file downloads
  • Hyperswarm — Topic-based peer discovery through a DHT and encrypted peer connections
  • Blossom specifications — HTTP blob-server protocol using SHA-256 addresses and Nostr identities

  • BEP 19: Web seeds — HTTP and FTP sources for torrent data
  • BEP 52: BitTorrent v2 — SHA-256-based torrent metadata and per-file Merkle trees
