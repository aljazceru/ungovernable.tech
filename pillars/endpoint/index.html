Browser Hardening

  • Arkenfox user.js — Firefox privacy, security, anti-tracking, and fingerprint-resistance configuration template
  • Tor Browser — Hardened Firefox browser routed through Tor for strong anonymity sets
  • LibreWolf — Firefox fork with privacy defaults, telemetry removal, and fingerprinting protections
  • Mullvad Browser — Tor Project and Mullvad privacy browser designed to reduce fingerprinting without Tor routing
  • uBlock Origin — Efficient wide-spectrum blocker for ads, trackers, malware, and coin miners
  • ClearURLs — Browser extension that removes tracking parameters from URLs
  • Privacy Possum — Browser extension that reduces and falsifies data collected by commercial trackers
  • Privacy Guides — Community-maintained recommendations for defending against mass surveillance

Mobile & Device Hardening

  • GrapheneOS — Android privacy and security hardening project for supported Pixel devices
  • Orbot — Tor VPN/proxy app for Android by Guardian Project
  • Rethink DNS + Firewall — Android encrypted DNS, WireGuard proxifier, app firewall, and connection tracker
  • TrackerControl — Android app for monitoring and blocking hidden tracker connections across installed apps
  • Exodus Privacy — Platform for auditing trackers and privacy risks in Android applications

DNS & Network Blocking

  • HaGeZi DNS Blocklists — Maintained DNS blocklists for ads, telemetry, phishing, malware, and tracking domains

Private Search

  • Whoogle Search — Self-hosted, ad-free Google metasearch proxy; final release in 2026 due to Google blocking

Fingerprinting Tests

  • CreepJS — Browser fingerprinting test suite for auditing how trackable a browser/device is
  • web-fingerprinting — Research collection covering fingerprinting papers, attacks, mitigations, and test suites
  • Browser Fingerprinting Resistance Research — Matrix comparing browser protections against common fingerprinting techniques

Passkeys and Security Keys

  • WebAuthn Level 3 — W3C public-key authentication specification: credentials, origin checks and backup state
  • FIDO passkeys — Definitions and guidance for synced and device-bound passkeys
  • FIDO authentication specifications — Official WebAuthn and CTAP specification references

Document Safety

  • Dangerzone — FPF tool that renders untrusted documents in isolation and rebuilds PDFs from pixels
  • mat2 — Metadata cleanup for supported documents, images and other file formats
  • ExifTool — Read and edit file metadata; PDF edits are reversible and need further sanitization
