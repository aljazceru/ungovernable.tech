#### MPC Overviews
- [A Pragmatic Introduction to Secure Multi-Party Computation](https://securecomputation.org/) - Free book introducing secure computation protocols and applications
- [awesome-mpc](https://github.com/rdragos/awesome-mpc) - Curated list of MPC software, papers, tutorials, and workshops
- [MPC Deployments](https://mpc.cs.berkeley.edu/) - UC Berkeley hub for real-world secure multi-party computation deployments

#### MPC Frameworks
- [MP-SPDZ](https://github.com/data61/MP-SPDZ) - Versatile framework for benchmarking MPC protocols across honest/dishonest majority and active/passive security models
- [EMP Toolkit](https://github.com/emp-toolkit/emp-agmpc) - Global-scale secure multi-party computation toolkit in C++
- [CrypTen](https://crypten.ai/) - PyTorch-based research framework for secure and privacy-preserving machine learning with MPC
- [SCALE-MAMBA](https://github.com/KULeuven-COSIC/SCALE-MAMBA) - MPC system supporting SPDZ-family protocols and malicious-security settings
- [FRESCO](https://github.com/aicis/fresco) - Java framework for efficient secure computation applications and protocol suites

#### MPC Applications
- [TLSNotary](https://tlsnotary.org/) - MPC-based protocol for proving facts about HTTPS sessions without revealing private data
- [PSE MPC Framework](https://github.com/privacy-scaling-explorations/mpc-framework) - TypeScript framework and demos for MPC-powered applications (sunset but useful reference)
- [Trinity](https://github.com/privacy-scaling-explorations/Trinity) - Two-party computation design combining laconic OT, garbled circuits, and PLONK
